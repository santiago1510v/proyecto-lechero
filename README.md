# proyecto-lechero
Descripción

Este proyecto busca implementar herramientas de programación para mejorar la organización financiera y el control de la producción de una finca lechera. Mediante el uso de Python y Streamlit, se desarrolla una aplicación que permite registrar, consultar y analizar información relacionada con la producción de leche y los gastos de la finca.

La finalidad es facilitar el control de los datos y apoyar la toma de decisiones económicas a partir de información organizada.

Objetivos

Organizar los registros de producción de leche.

Llevar un control de los gastos de la finca.

Analizar los datos mediante cálculos y gráficas.

Facilitar la comprensión del comportamiento económico y productivo.

Tecnologías utilizadas

Python

Streamlit

Pandas

Plotly

GitHub

Datos

El proyecto utiliza registros reales de una finca familiar. Debido a la disponibilidad de información, se trabaja con los datos recopilados hasta la fecha, los cuales permiten desarrollar y probar las funcionalidades de la aplicación.

Aplicación

La aplicación permite visualizar información de producción y gastos, consultar registros y analizar los datos disponibles.
